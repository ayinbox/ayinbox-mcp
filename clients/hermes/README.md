# Hermes Agent

Merge `config.yaml` into the `mcp_servers:` block of `~/.hermes/config.yaml`, then run `hermes mcp login ayinbox` to sign in (add `--flow device` on a machine with no browser). For an API key use `config.api-key.yaml` and replace `aybox_...` with your key. Source: https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp

To call AY Inbox tools from Hermes without MCP, the same tools are on the REST API in Hermes format: see https://docs.ayinbox.com/api/agent-tools/.
