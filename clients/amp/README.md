# Amp

Run `amp mcp add ayinbox https://api.ayinbox.com/v1/mcp`, or merge `settings.json` into `~/.config/amp/settings.json`. Amp opens the browser to sign in when it starts. For an API key use `settings.api-key.json`: Amp replaces `${AYINBOX_API_KEY}` with the environment variable. In a workspace `.amp/settings.json`, approve the server first with `amp mcp approve ayinbox`. Source: https://ampcode.com/docs/customize/mcp
