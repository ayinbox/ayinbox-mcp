# Claude (web and desktop)

In Claude, open **Customize > Connectors**, choose **Add**, then **Add custom connector**. Name it AY Inbox, paste `https://api.ayinbox.com/v1/mcp` as the URL, choose **Continue**, keep the options Claude marks as detected, choose **Add**, then **Connect** and sign in to AY Inbox in the browser that opens. On a Team or Enterprise plan an owner adds it under **Organization settings > Connectors > Add > Custom > Web**, and each member then finds it under **Customize > Connectors** and chooses **Connect**. There is no file to copy for this client. Custom connectors sign in with OAuth; request headers for an API key are a beta that only some organizations have, so for a key in Claude Desktop use the bridge in [`../claude-desktop/`](../claude-desktop/). Source: https://claude.com/docs/connectors/custom/remote-mcp
