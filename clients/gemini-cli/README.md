# Gemini CLI

OAuth: `gemini mcp add --transport http --scope user ayinbox https://api.ayinbox.com/v1/mcp`, or merge `settings.json` into `~/.gemini/settings.json`. Gemini CLI finds the sign-in on the first `401`; run `/mcp auth ayinbox` to sign in or sign in again. `httpUrl` is the streamable HTTP field (`url` means SSE). For an API key, `gemini mcp add --transport http --scope user --header "Authorization: Bearer $AYINBOX_API_KEY" ayinbox https://api.ayinbox.com/v1/mcp` writes the key your shell expands; `settings.api-key.json` is the same entry by hand with the key pasted in, since the docs document variable expansion for `env` only. This repository is also a Gemini CLI extension: `gemini extensions install https://github.com/ayinbox/ayinbox-mcp`. Source: https://geminicli.com/docs/tools/mcp-server/
