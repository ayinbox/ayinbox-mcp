# Changelog

## 1.0.0

- `server.json` for the official MCP Registry as `com.ayinbox/ayinbox`: one streamable HTTP remote at `https://api.ayinbox.com/v1/mcp`, OAuth by default and an optional `Authorization` header for an API key.
- Connect steps and ready-to-copy config for 22 MCP clients in `README.md` and `clients/`.
- Gemini CLI extension, Claude Code plugin and the `ayinbox` agent skill.
- `PUBLISH.md` with the registry publishing steps.
